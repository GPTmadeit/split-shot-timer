## Where to ask

| I want to... | Go to |
| --- | --- |
| Ask how something works, or get setup help | [Discussions](https://github.com/GPTmadeit/split-shot-timer/discussions) |
| Report shots being missed or miscounted | [Detection accuracy report](https://github.com/GPTmadeit/split-shot-timer/issues/new?template=detection_accuracy.yml) |
| Report a bug | [Bug report](https://github.com/GPTmadeit/split-shot-timer/issues/new?template=bug_report.yml) |
| Suggest a feature or a drill | [Feature request](https://github.com/GPTmadeit/split-shot-timer/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [Privately](SECURITY.md) — please not a public issue |

## What helps get a useful answer

- The release version, or commit SHA if you built from source.
- Your watch and phone models and OS versions.
- What Settings shows for audio source and sample rate (e.g. `UNPROCESSED @ 48000 Hz`).
- For detection problems: firearm, calibre, suppressed or not, indoor or outdoor, and your
  sensitivity / clip gate / blanking settings.

## Expectations

This is a hobby project maintained by one person in their spare time, and **it has never been
run on real hardware**. There is no guaranteed response time, and some questions may not have a
good answer yet.

Detection reports from real range sessions are the most valuable thing anyone can send, and get
looked at first.
